Build notes

Inputs are TextInput with a visible label above (never placeholder-only). Mark email as textContentType emailAddress, keyboardType email-address, autoCapitalize none, and the password as textContentType password so iOS can offer saved passwords. Checkboxes are a Pressable with accessibilityRole checkbox and accessibilityState checked, since React Native has no built-in checkbox. The check mark is two rotated Views drawn with borders, so no icon library is needed. Wrap each form in KeyboardAvoidingView and ScrollView so the primary button stays reachable.

Content decisions to confirm

The "Your recordings" card on the consent screen is a placeholder: [DATA HANDLING: where recordings are stored, who can see them, and how to delete them]. I have not invented a privacy claim, so please supply the real text. "Check your email" does not confirm whether an account exists, which is standard practice.
